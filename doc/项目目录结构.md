# MBox 项目目录结构总览

> 目的：对整个 TVBoxOS-Mobile(MBox) 工程做一次目录级的大概览，说明每个模块、每个包的职责与关键类，便于快速定位代码与理解架构。
> 适用版本：2.2.0（versionCode 43），Gradle 8.4 / AGP 8.2.2 / Kotlin 1.9.22，minSdk 24 / targetSdk 34。
> 说明：本文件随模块化重构（doc/module-refactor-design.md）持续更新；核心业务已拆为 6 个独立 gradle 模块 + ui-common 资源模块。

---

## 一、工程总览

```
TVBoxOS-Mobile/
├── app/                    # 主应用模块（唯一 application，UI 薄层）
├── player/                 # 播放器内核模块：ijk / EXO（DKVideoPlayer 封装）
├── player-api/             # 播放统一门面（引擎无关契约 PlayerApi，Media3 升级铺路）
├── common/                 # 公共基础库：HawkConfig / OkGoHelper / HttpClient / 事件 / 工具
├── ui-common/              # 公共 UI 资源模块：主题 / 颜色 / 样式 / 通用 drawable（零业务依赖）
├── log/                    # 日志中心：LogStore（Room 业务日志 + logcat 捕获 + 7 天）
├── state/                  # 系统状态监控：SystemStateMonitor（网络/前后台/锁屏/横竖屏/电量/磁盘）
├── spider/                 # 爬虫模块：SpiderApi 门面 + JsLoader/JarLoader + 解析 + util.js
├── download/               # 下载模块：DownloadFacade + 任务对象化 + 调度/执行/策略/档案
├── crash/                  # 崩溃兜底页模块（CustomActivityOnCrash 库）
├── quickjs/                # QuickJS JS 引擎 Android 封装模块
├── TabLayout/              # 第三方 TabLayout 组件库（com.angcyo.tablayout）
├── ViewPager1Delegate/     # ViewPager1 委托库（配合 TabLayout）
├── doc/                    # 项目文档（md）
├── scripts/                # 构建辅助脚本（PowerShell: 资源命名校验；Python: SVG/PNG → Vector）
├── .github/workflows/      # CI 工作流（push main/v* 标签或手动触发 release 构建）
├── gradle/wrapper/         # Gradle Wrapper(8.4)
├── settings.gradle         # 模块声明（rootProject.name = "TVBoxMobile"）
├── build.gradle            # 根构建脚本（插件版本、仓库、公共配置）
├── gradle.properties       # JVM 参数 / AndroidX / nonTransitiveRClass=false
├── TVBoxOSC.jks            # release 签名文件（已入库，CI 与本地共用正式签名）
├── README.md / LICENSE     # 项目说明与协议
└── local.properties        # 本机 SDK 路径（不入库）
```

### 模块依赖关系

```
app ──┬──> player ──> (TabLayout → ViewPager1Delegate)
      ├──> player-api         # 播放契约（独立，app/player 双向不依赖）
      ├──> quickjs
      ├──> crash
      ├──> common             # 基础库（无 project 依赖）
      ├──> ui-common          # 公共资源（依赖 appcompat/material）
      ├──> log                # 依赖 common
      ├──> state              # 依赖 log
      ├──> spider             # 依赖 common / log / quickjs
      └──> download           # 依赖 common / log / spider（PlayUrlResolver）
```

## 十二、目录整理说明（最近一次）

- **空目录清理**：删除 `app/.../api`、`app/.../event`、`app/.../util/rsa`（对应实现已迁 spider/common 模块）；
- **类归位**：`LivePlayerManager`（原 bean 包）→ `util` 包（管理器非数据模型）；
- **死代码清理**：`ui/tv/QRCodeGen.java`（全仓库无引用，zxing 调用方自带生成逻辑）；
- **主题迁移**：`assets/theme/*.json` 与 `generateThemeColors` 任务 → `ui-common`（app 只留页面级资源）。

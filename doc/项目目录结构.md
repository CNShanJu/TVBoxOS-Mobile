# MBox 项目目录结构总览

> 目的:对整个 TVBoxOS-Mobile(MBox) 工程做一次目录级的大概述,说明每个模块、每个包的职责与关键类,便于快速定位代码与理解架构。
> 适用版本:2.1.31(versionCode 42),Gradle 8.4 / AGP 8.2.2 / Kotlin 1.9.22,minSdk 24 / targetSdk 34。

---

## 一、工程总览

```
TVBoxOS-Mobile/
├── app/                    # 主应用模块(唯一 application,其余均为 library)
├── player/                 # 播放器模块(ijk / EXO / 第三方播放器壳)
├── crash/                  # 崩溃兜底页模块(CustomActivityOnCrash 库)
├── quickjs/                # QuickJS JS 引擎 Android 封装模块
├── TabLayout/              # 第三方 TabLayout 组件库(com.angcyo.tablayout)
├── ViewPager1Delegate/     # ViewPager1 委托库(配合 TabLayout)
├── doc/                    # 项目文档(md)
├── scripts/                # 构建辅助脚本(Python:SVG/PNG → Vector)
├── .github/workflows/      # CI 工作流(手动触发 release 构建)
├── gradle/wrapper/         # Gradle Wrapper(8.4)
├── settings.gradle         # 模块声明(rootProject.name = "TVBoxMobile")
├── build.gradle            # 根构建脚本(插件版本、仓库、公共配置)
├── gradle.properties       # JVM 参数 / AndroidX / nonTransitiveRClass=false
├── TVBoxOSC.jks            # release 签名文件(app/build.gradle 引用)
├── README.md / LICENSE     # 项目说明与协议
└── local.properties        # 本机 SDK 路径(不入库)
```

### 模块依赖关系

```
app ──► player ──► TabLayout ──► ViewPager1Delegate
  ├──► quickjs
  ├──► crash
  └──► (本地 jar: libs/thunder.jar、commons-lang3、dec.jar)
```

| 模块 | 类型 | namespace | 职责 |
|---|---|---|---|
| `app` | application | `com.github.tvbox.osc` | 主应用:UI、数据、下载、播放调度、主题 |
| `player` | library | `com.github.tvbox.osc.player` | 播放器封装:ijk/EXO 双内核 + 第三方播放器跳转 |
| `crash` | library | `cat.ereza.customactivityoncrash` | 崩溃后兜底 Activity(自带 res) |
| `quickjs` | library | `com.whl.quickjs.android` | QuickJS 引擎 JNI 封装(js 爬虫执行) |
| `TabLayout` | library | `com.angcyo.tablayout` | 三方 TabLayout 组件(Kotlin) |
| `ViewPager1Delegate` | library | `com.angcyo.tablayout.delegate` | ViewPager1 委托支持 |

## 六、关键数据流(快速导航)

1. **点播**:`ApiConfig`(源/订阅) → `SearchHelper`/`FastSearchActivity` → `DetailActivity`(选集) → `PlayFragment` + `VodController` → `EXOmPlayer`/`IjkMediaPlayer`
2. **下载**:`DetailActivity#showDownloadSeriesDialog` → `DownloadManager`(spThreadPool 解析 → 直链/HLS 分片下载 → 校验/合并) → `DownloadActivity`/`DownloadFragment`
3. **直播**:`LiveActivity` + `LiveController`(频道/EPG/设置弹层)
4. **JS 爬虫**:`SourceViewModel.spThreadPool`(单线程) → `SpiderJS`/`JsLoader`(quickjs 引擎) → 解析结果回传
5. **主题**:构建期 `generateThemeColors` 生成 `values(-night)/colors.xml`,运行时由 `App` 按配置切换
6. **崩溃兜底**:`crash` 模块在 `App.onCreate` 注册,崩溃后展示自定义页并写日志(`LogActivity` 可查看)

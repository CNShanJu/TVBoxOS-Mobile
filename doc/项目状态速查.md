# MBox 项目状态速查(2026-08-16)

> 目的:压缩对话上下文,后续需求直接引用本文件,避免重复说明。
> 构建:`$env:JAVA_HOME="D:\Environment\Jdk\main\jdk17"; .\gradlew.bat assembleDebug`
> APK: `app/build/outputs/apk/debug/MBox_v2.0.0_debug.apk`(debug);release 同目录

## 版本与基础
- 版本 2.0.0(versionCode 40),包名 `com.github.tvbox.osc`(debug 加 `.debug`),App 名 MBox
- Gradle 8.4 / AGP 8.2.2 / Kotlin 1.9.22 / SDK 34 / minSdk 24 / Material 1.9.0 / okhttp4

## 主题配置(重点)
- `app/src/main/assets/theme_colors.json`(浅)+ `theme_colors_night.json`(暗),**字段一致**:`bg_body/bg_component/text_main/text_highlight/nav_text_normal`;gitignored,本地打包生效
- 构建时 `generateThemeColors` 任务生成 values/values-night 两套色;`colors.xml` 核心色引用它们
- 高亮/选中统一用 `@color/color_highlight`(#1890FF 蓝);播放控制抽屉为**固定深色 #1F1F1F + 白字**(不随主题)

## 统一组件
| 组件 | 位置 | 说明 |
|---|---|---|
| AppTitleBar | `ui/widget/AppTitleBar.java` | 标题栏:bg_body 背景/text_main 文字/图标,返回键跟随主题;7 个二级页使用 |
| AppSwitch | `ui/widget/AppSwitch.java` | 开关:轨道=text_main(固定)、圆点=白;设置页 4 处 |
| RoundChip | `ui/widget/RoundChip.java` | 圆角+文字:选中=蓝无背景,未选中=colorPrimary;选集 item_series 用 |
| AppDrawerPopupView | `ui/dialog/AppDrawerPopupView.java` | 右侧抽屉基类:圆角+bg_popup;5 个抽屉已继承 |

## 主要功能
- **下载**:DownloadManager(并发1-5/断点续传/来源+剧名目录/m3u8→mp4/查重),入口=我的-下载;下载页两级(正在下载按剧名分组/下载完成按来源剧名文件夹),复用本地视频组件
- **运行日志**:设置开关(默认关)+ logcat 完整捕获;LogActivity 独立页(底部抽屉选日期、复制、滚底、清空、导出)
- **直播**:直播源默认 `https://live.zbds.top/tv/iptv4.txt`;TxtSubscribe 支持 M3U+txt;加载失败 Toast+空态(无强制超时);播放失败同频道线路自动切、全挂停止提示,不自动切频道
- **字幕**:默认关;弹窗内选项仅"打开字幕"时显示;"✓ 打开字幕"高亮、"关闭字幕"无勾
- **播放设置抽屉**:固定深色白字;缩放/播放器点击弹 SelectDialog 列出全部选项;倍速选中=蓝字
- **订阅**:默认订阅 `assets/default_subscriptions.json`(gitignored);ApiConfig.FindResult 处理 BOM/注释/图片+base64 套路

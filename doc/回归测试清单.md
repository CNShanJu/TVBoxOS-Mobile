# 回归测试清单（模块化重构后）

> 适用：本地 debug 包（`app/build/outputs/apk/debug/MBox_v2.2.0_debug.apk`）。
> 前置：安装 debug 包前先卸载旧同包名应用（debug 包名带 `.debug` 后缀，可与正式版共存）。
> 辅助：logcat 过滤 `ToastTrace` 可查看每个 toast 的触发调用栈（仅 debug 包）。

## 一、下载模块（改动最重，优先级最高）

| # | 用例 | 操作 | 预期 |
|---|---|---|---|
| 1 | 入队 | 详情页选集 → 下载 | 任务入队，正在下载 tab 出现，通知栏显示"正在下载 N 个任务"（前台服务） |
| 2 | 并发调度 | 一次性下载 ≥4 集 | 同时下载数 = 设置并发数，其余排队；调低并发（设置-并发）后多余任务转"调度暂停" |
| 3 | 排队插队 | 下载 3 集时对第 4 集"置顶/加优先级" | 高优先级任务先启动；并发满时低优先级被抢占让位 |
| 4 | 直链断点续传 | 下载中杀进程 → 重启 → 继续下载 | 从 .part 现场续传（Range），不重下 |
| 5 | HLS 下载 | 下载 m3u8 源 | 分片下载→校验→合并→重封装 mp4；相册时长/缩略图正确 |
| 6 | HLS 缺失补片 | 下载中手动删 tmpDir 部分 .ts → 继续 | 校验发现缺失，自动补下（日志"补片/片N"），最终合并成功 |
| 7 | 暂停/恢复 | 暂停→恢复 | 状态 PAUSED→DOWNLOADING，从断点续传 |
| 8 | 删除 | 删除正在下载的任务（勾选删文件） | 任务移除 + CANCELLED 中止 + 连接关闭 + 碎片删除 |
| 9 | 完成档案 | 下载完成 | 完成 tab 出现（档案表），文件在 来源/剧名/ 目录 |
| 10 | 重命名 | 完成 tab 重命名 | 文件与档案同步改名 |
| 11 | 删除档案 | 完成 tab 删除（联动删文件） | 档案消失 + 文件删除 |
| 12 | 仅 WiFi | 开"仅WiFi"→ 切蜂窝 | 下载任务转"网络暂停"（NETWORK_PAUSED），恢复 WiFi 自动续传 |
| 13 | 磁盘预检 | 磁盘空间不足时下载 | 启动即失败并提示需清理量级 |
| 14 | 限速 | 下载中设置限速 | 下载速度被限制（设置项/策略） |
| 15 | 完成通知 | 完成一个任务 | 系统通知"下载完成"，点击打开文件 |
| 16 | 任务日志 | 完成/失败任务 → 详情查看日志 | 展示 7 天内的任务日志（入队/分片/校验/补片/合并/落盘/清理） |

## 已知注意（回归时留神）

- **本地 aTrust 网络**：GitHub 直连不稳，push 需 `-c http.proxy=http://127.0.0.1:7890`；部分源 403/JPEG 为 IP 风控（非 app bug）。
- **真机优先**：播放轨道/字幕/画中画建议真机验证（模拟器易漏）。
- **升级路径**：旧版（重构前）升级到新包，Hawk 配置键兼容（play_type 等沿用旧 key），设置不丢。
- 若发现 toast 来源为**系统/第三方库**（非 AppBubble 路径），ToastTrace 不会捕获——需在对应库调用点另查。
